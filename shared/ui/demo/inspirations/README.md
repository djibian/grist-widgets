# Variations Linear — icônes nues

Cette maquette conserve uniquement la direction visuelle Linear retenue pour la suite.

Le contenu, la palette, les onglets et toute l’interface restent identiques. Les actions `Actualiser` et `Réglages` restent toujours **sans cadre, sans fond et sans libellé**. Seul le langage graphique des pictogrammes change :

- `?variant=solid` : formes pleines, compactes et monochromes ;
- `?variant=bold` : trait rond très épais ;
- `?variant=duo` : forme sombre + détail coloré ;
- `?variant=color` : icône entière colorée selon l’action ;
- `?variant=geo` : pictogrammes très géométriques et synthétiques ;
- `?variant=accent` : forme sombre + petit accent coloré.

L’objectif est d’identifier une famille d’icônes plus symbolique et plus présente que les premiers tracés fins, tout en conservant la sobriété de l’interface Linear.

Aucun widget réel n’utilise ces styles : cette page sert uniquement à arbitrer l’interface avant migration.
