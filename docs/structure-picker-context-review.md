## Conventions appliquées

| Champ | Convention | Exemple |
|---|---|---|
| Nom usuel | Casse de phrase et commune systématique, accents préservés ; initiales de marque isolées conservées | Espace et vie — Pornic ; Super U — Machecoul-Saint-Même |
| Adresse physique | Numéro et suffixe, type de voie en minuscules, noms propres lisibles, code postal et commune ; sans BP/CS/CEDEX redondants | 10 ter place du Champ de Foire, 44650 Legé |
| SIRET | 3 + 3 + 3 + 5 chiffres, séparés par des espaces | 268 500 659 00027 |
| SIREN | 3 + 3 + 3 chiffres | 214 400 814 |
| Téléphone français | Cinq groupes de deux chiffres séparés par des points | 02.51.74.33.00 |
| Raison sociale | Dénomination officielle du registre ; gestionnaire explicité si nécessaire | COMMUNE DE LEGE |

Les différences de présentation sont systématiquement proposées. Les améliorations confirmées d’une valeur existante sont précochées. Une analyse incomplète n’empêche pas de corriger la présentation des valeurs déjà saisies, sans importer une identité juridique incertaine. Aucune donnée Grist n’est modifiée pendant l’analyse.

Le nom inclut toujours la commune : cela évite de dépendre d’une connaissance exhaustive des homonymes sur le territoire. Le retrait du suffixe à l’analyse suivante porte sur la commune complète, sans effacer un nom propre comme « Saint-Christophe » présent dans le nom du lieu.

## Modifications de l’algorithme

Le résolveur combine le nom, l’adresse, les contacts, les identifiants sectoriels, les captures légales datées et, en complément, une raison sociale déjà saisie. Les coordonnées géocodées de rue ou d’administration ne deviennent pas une position finale. Un point d’entrée natif, explicitement publié et certifié par la commune, est admissible avec une adresse physique déjà confirmée ; ce modèle conserve sa portée d’entrée et n’annonce pas une précision de toit. Les décisions restent calculées à l’exécution ; aucun résultat attendu ni numéro de ligne Grist n’est utilisé par le résolveur.

Les preuves locales sont évaluées ensemble avant les services distants. Le cache géographique conserve tous les lieux nommés/adressés/géolocalisés des neuf captures postales fournies : 4 423 observations, sans sélection par nom ou SIRET. Chaque fichier conserve la date/version source et l’empreinte de la capture complète. Les réponses légales sont contrôlées par empreinte SHA-256, identifiant, état actif et fraîcheur maximale de 30 jours ; une capture expirée n’est pas réutilisée comme preuve actuelle.

Les remplacements confirmés sont sélectionnés par défaut ; les preuves et coordonnées restent atomiques avec l’identité correspondante. Les colonnes calculées/non mappées et les changements intervenus dans la fiche depuis l’analyse restent contrôlés. Un doublon existant du même lieu peut être corrigé sans fusion ni suppression ; un numéro appartenant à un autre lieu reste bloqué. Une position existante déjà démontrée n’est pas précochée pour être remplacée par une preuve plus faible.
